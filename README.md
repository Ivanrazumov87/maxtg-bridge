# Двусторонний мост MAX ⇄ Telegram (режим тем/топиков)

Бот зеркалит сообщения между мессенджером MAX и Telegram **в обе стороны**.
Каждый чат MAX отображается **отдельной темой (топиком)** в форум-супергруппе
Telegram: новые сообщения из MAX попадают в свою тему, а написанное вами в тему
уходит обратно в соответствующий чат MAX.

По вопросам заходите в [тг](https://t.me/intchaserlive) (там же видео-инструкция по установке бота).
Используйте на свой страх и риск, шанс бана не нулевой.

### Если нужны кастомные боты / приложения Android и т.п. - [обращайтесь](https://t.me/starchasercc)

## ✨ Возможности

- 🔄 **Двусторонняя** пересылка: MAX → Telegram и Telegram → MAX
- 🧵 Каждый чат MAX = отдельная **тема (топик)** в одной супергруппе Telegram
- 🌐 По умолчанию пересылаются **все** чаты MAX (можно сузить whitelist'ом)
- 🆕 Темы создаются автоматически при первом сообщении из нового чата
- ♻️ Защита от эхо-петли (ваш ответ из Telegram не дублируется обратно)
- 📸 Поддержка медиа — текст и фотографии

## ⚠️ Ограничения

На текущий момент бот поддерживает не все типы сообщений. **Полностью работают:**
- ✅ Обычные текстовые сообщения
- ✅ Изображения
- ✅ Пересланные сообщения
- ✅ Файлы кроме изображений отбражаются как необработанные файлы

- 🔄 Обработка остальных типов сообщений находится в разработке 
- 🔄 Если отправлено несколько сообщений за короткий промежуток времени - то большинство из них не перешлются

## 📥 Установка и настройка

### Шаг 1: Клонирование и установка зависимостей

Скачайте файлы бота в папку проекта и установите зависимости:

`pip install -r requirements.txt`

### Шаг 2: Получение токена MAX

1. Зайдите в **чат** [нашей группы](https://t.me/intchaserlive) и следуйте туториалу из закрепа

### Шаг 3: Настройка Telegram бота

1. Найдите в Telegram **@BotFather**
2. Отправьте команду `/newbot`
3. Придумайте имя для бота
4. Придумайте username для бота
5. **Скопируйте токен** который выдаст @BotFather

### Шаг 4: Создание форум-супергруппы и получение её ID

Все чаты MAX будут темами **одной** супергруппы Telegram.

1. Создайте в Telegram **группу** и сделайте её **супергруппой** (добавьте любого
   второго участника / откройте настройки группы).
2. В настройках группы включите **«Темы» (Topics)**.
3. Добавьте туда бота из шага 3 и назначьте его **администратором** с правом
   **«Управление темами»** (Manage Topics).
4. Узнайте **ID супергруппы**: перешлите боту [@my_id_bot](https://t.me/my_id_bot)
   любое сообщение из этой группы. ID супергруппы обычно начинается с `-100…`.

**ID чата в MAX** (нужен только если хотите ограничить список чатов whitelist'ом):
1. Откройте [веб-версию MAX](https://web.max.ru)
2. Перейдите в нужный чат
3. ID — в адресной строке (`https://web.max.ru/ID_ЧАТА`)

### Шаг 5: Настройка конфигурации

Скопируйте `.env.example` в `.env` и заполните:
```
MAX_TOKEN=токен из шага 2
MAX_CHAT_IDS=                # пусто = все чаты; либо ID через запятую (whitelist)
TG_BOT_TOKEN=токен из шага 3
TG_GROUP_ID=-100…            # ID форум-супергруппы из шага 4
MONITOR_ID=                  # необязательно: ID чата для уведомлений встал/упал
```
## 🚀 Запуск бота

После завершения всех настроек запустите бота:

`python starter.py`

Если в консоли нет ошибок - бот успешно запущен и начал мониторить сообщения!

## 🎯 Проверка работы

**MAX → Telegram:**
1. Отправьте тестовое сообщение в любой чат MAX.
2. Через несколько секунд в супергруппе появится **тема** с названием чата, а в ней — сообщение.

**Telegram → MAX:**
1. Откройте нужную тему в супергруппе и напишите туда сообщение.
2. Оно уйдёт в соответствующий чат MAX. Его эхо обратно в тему **не дублируется**.

## 🧩 Как это работает

- При первом сообщении из чата MAX бот вызывает `createForumTopic` и запоминает
  связь `chat_id ⇄ message_thread_id` в файле `bridge_state.json`.
- Соответствия и offset Telegram переживают перезапуск (хранятся на диске).
- Приём из Telegram — long-polling (`getUpdates`), поэтому вебхук не нужен.

## ⚠️ Заметки и ограничения

- Бот **обязан** быть админом супергруппы с правом «Управление темами», иначе темы
  не создаются.
- Имя темы для личных диалогов берётся из имени собеседника, для групп/каналов —
  из их названия (`title`). Если имя не удалось получить — тема называется «Чат <id>».
- Из Telegram в MAX пересылаются **текст, фото, видео и документы** (файлы),
  включая видео-кружочки. Прочие типы (стикеры, голосовые) пока не заливаются.
- Не удаляйте `bridge_state.json` — иначе бот «забудет» соответствие тем и создаст их заново.

**Примечание**: Для постоянной работы рекомендуется запускать бота на VPS или домашнем сервере, который работает 24/7.
